# PhoneLink — ম্যাক ↔ অ্যান্ড্রয়েড

## বিল্ড (ফোন থেকেই)
1. এই পুরো ফোল্ডার GitHub রিপোজিটরিতে আপলোড করুন (main ব্রাঞ্চ)।
2. Actions ট্যাবে "Build" রান হবে। শেষে Artifacts থেকে `PhoneLink-APK` ও `PhoneLink-DMG` নামান।

## ব্যবহার
1. ফোনে APK ইনস্টল করে খুলুন, সব পারমিশন দিন। স্ক্রিনে আইপি ও পিন দেখাবে।
2. ম্যাকে DMG খুলে PhoneLink কে Applications-এ টেনে দিন। প্রথমবার ডান ক্লিক → Open।
3. মেনু বারের 📱 আইকনে ক্লিক → সেটিংস → আইপি ও পিন দিন।

## ফিচার
- কল: ফোনে কল এলে ম্যাকে নোটিফিকেশন, ম্যাক থেকে ধরা/কাটা/ডায়াল
- ক্লিপবোর্ড দুই দিকে, ম্যাক থেকে ফোনে ফাইল (Download/PhoneLink)
- ব্যাটারি: মেনুতে পার্সেন্টেজ ও চার্জিং, ১৫% এর নিচে গেলে সতর্কবার্তা
- নোটিফিকেশন: ফোনের নোটিফিকেশন ম্যাকে দেখায় (মেনু থেকে অন/অফ)
- লোকেশন: মেনুতে ক্লিক করলে ফোনের অবস্থান গুগল ম্যাপে খোলে
- স্ক্রিন: ফোনের স্ক্রিন ম্যাকের উইন্ডোতে (শুধু দেখা)

## একবারের সেটআপ (ফোনে)
- নোটিফিকেশন: অ্যাপে "নোটিফিকেশন অ্যাক্সেস চালু করুন" চেপে PhoneLink অন করুন।
  Android 13+ এ না হলে: সেটিংস → অ্যাপ → PhoneLink → ⋮ → "Allow restricted settings"।
- স্ক্রিন: প্রতিবার অ্যাপে "স্ক্রিন শেয়ার চালু করুন" চেপে অনুমতি দিতে হবে।
- লোকেশন: ফোনের লোকেশন (GPS) অন রাখুন।
