# PhoneLink — ম্যাক ↔ অ্যান্ড্রয়েড

## বিল্ড (ফোন থেকেই)
1. এই পুরো ফোল্ডার GitHub রিপোজিটরিতে আপলোড করুন (main ব্রাঞ্চ)।
2. Actions ট্যাবে "Build" রান হবে। শেষে Artifacts থেকে `PhoneLink-APK` ও `PhoneLink-DMG` নামান।

## ব্যবহার
1. ফোনে APK ইনস্টল করে খুলুন, সব পারমিশন দিন। স্ক্রিনে আইপি ও পিন দেখাবে।
2. ম্যাকে DMG খুলে PhoneLink কে Applications-এ টেনে দিন। প্রথমবার ডান ক্লিক → Open।
3. মেনু বারের 📱 আইকনে ক্লিক → সেটিংস → আইপি ও পিন দিন।

## ফিচার
- ফোনে কল এলে ম্যাকে নোটিফিকেশন (নাম/নম্বর), ম্যাক থেকে কল ধরা/কাটা
- ম্যাক থেকে নম্বর দিলে ফোন থেকে কল যায়
- ক্লিপবোর্ড দুই দিকে পাঠানো
- ম্যাক থেকে ফোনে ফাইল পাঠানো (Download/PhoneLink ফোল্ডারে)

দ্রষ্টব্য: কলে কথা ফোনেই হয়, ম্যাকের মাইক/স্পিকারে নয়।
